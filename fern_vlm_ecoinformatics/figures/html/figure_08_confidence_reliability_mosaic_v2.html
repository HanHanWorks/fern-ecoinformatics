Figure 8 v2. Self-reported confidence is not a safe acceptance criterion

A confidence-versus-accuracy comparison, high-confidence error panel, and error taxonomy matrix for the main direct30 benchmark.

Detailed content

Panel A visualizes overconfidence by linking observed family accuracy to mean self-reported confidence. Panel B turns that gap into a deployment statistic by reporting the proportion of high-confidence errors. Panel C shows the main error categories on the direct30 benchmark, highlighting same-group confusions, dominant-family attraction, and page-text cues.

The main message is practical rather than rhetorical: confidence values from general-purpose VLMs should not be used as an acceptance rule without additional calibration and expert review.
