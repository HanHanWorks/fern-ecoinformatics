Figure 1 v2. Ecological-informatics workflow audited in this study

A graphical workflow that frames the paper as a reliability audit of VLM-assisted biodiversity data processing, not a model ranking exercise.

Detailed Content

This public v2 workflow figure uses a schematic image-evidence placeholder to avoid redistributing restricted local reference images. The workflow proceeds from image evidence to source audit, VLM inference, reliability gates, expert review, and final database status. The lower evidence cards connect the workflow to the actual experiments: closed-set direct30, text masking, candidate-order perturbation, external validation, open-set rejection, and confidence audit.

The figure is designed for the Introduction or the first Methods subsection. It tells editors that the paper is an ecological data workflow audit, not a leaderboard.

Data and Rights Notes

Numbers shown: best direct30 family accuracy 60.6%; random baseline 3.3%; majority baseline 27.7%; external validation 33.3%-43.3%; open-set negative rejection 73.3%-91.7%; order consistency 78.3%-95.0%.

The public version does not embed local reference-book images. Restricted local images and text-masked derivatives are not redistributed.
